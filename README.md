# tesla-research-pages

Internal research briefs written by Tesla for Patrick Sotello / Conquest AI.

Hosted on a free Render `*.onrender.com` subdomain so a report can be opened in one tap. This is not a client site and is not published on questwon.com or any other brand domain.

- Pages should be self-contained HTML (`noindex`).
- New briefs go in this repo as `/name.html` and are listed on the index.
